## Автотесты (pytest)

`python -m pytest -q` → **25 passed** (0.8 с). Покрытие критической логики:

| Область | Тесты |
|---|---|
| Нормализация | разбор цен (7 форматов), ключи моделей (SGTR02, UG10, AG300, TT106, REINVOX-DUO, HDE2020), категории и типы изделий, вместимость только из названия, очистка невидимых символов Tilda |

| Сопоставление | прямые аналоги, порог ≥3 сопоставимых для ценового сигнала, защита от повторных сигналов, генерация рекомендации без запрещённых формулировок |

| База | идемпотентность миграций |

## Известные ограничения

- Сбор с 12 страниц конкурентов не даёт цен (JS/картинки) — статус «empty» виден в «Источниках».
- Google Trends периодически отвечает 429: сборщик ждёт 70 с между группами; при повторном 429 часть групп пропускается до следующего запуска.
- zakupki.gov.ru: сертификат российского УЦ не входит в системное хранилище — соединение без проверки сертификата (только чтение публичных данных).
