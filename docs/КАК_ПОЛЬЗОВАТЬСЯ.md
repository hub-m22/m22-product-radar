# Как пользоваться M22 Product Radar (простая инструкция)

## Запуск
1. На рабочем столе есть файл **«Запустить радар»**. Дважды щёлкните по нему.
2. Откроется чёрное окно и через несколько секунд браузер со страницей радара (адрес http://127.0.0.1:8022).
3. Чёрное окно не закрывайте, пока работаете. Закрыли окно — радар выключился. Ничего не сломается, данные сохраняются.
4. Если браузер не открылся сам, откройте любой браузер и введите адрес `127.0.0.1:8022`.

## Обновление данных
- Пока чёрное окно открыто, радар сам собирает данные каждую ночь (сайты M22 в 05:00, конкуренты в 06:00, отчёт по понедельникам в 08:30).
- Если компьютер ночью выключен, раз в неделю запускайте файл **«Обновить данные радара»** на рабочем столе. Он работает 15–25 минут, потом пишет «Готово».
- Обновить вручную в любой момент можно и внутри радара: раздел «Источники» → кнопки «Собрать конкурентов», «Пересчитать анализ».

## Что смотреть (5 минут в неделю)
1. **Главная** — пять ответов вверху: что произошло, почему важно, что делать, приоритет, можно ли доверять. Ниже — главные сигналы и таблица действий.
2. **Рекомендуемые действия** — список конкретных дел с приоритетом (P1 — срочно), основанием и сроком. Откройте действие → нажмите «Принять», «В работу» или «Отклонить», при желании напишите комментарий и назначьте ответственного.
3. **Отчёты** — нажмите «Сформировать отчёт»; получите отчёт на 10 разделов. Кнопки PDF/XLSX — чтобы отправить коллегам.
4. **Сигналы** — все факты по рынку. Фильтры сверху: категория, важность, статус. Кнопка «Отправить на исследование» у сигнала создаёт карточку в «Новых возможностях».
5. **Новые возможности** — идеи новых товаров с аргументами за и против, а также найденные тендеры.

## Как читать сигнал
- **Подтверждённый факт** — точно так, как написано (цены сняты с сайтов, ссылка «источник» рядом).
- **Аналитический вывод** — расчёт по данным, смотрите процент уверенности.
- **Гипотеза** — предположение, требует проверки.
- Уверенность 75% и выше — можно действовать; ниже 60% — сначала проверьте вручную по ссылке.

## Частые действия
- **Добавить конкурента**: «Конкуренты» → форма внизу → название, сайт, ссылка на страницу товара → «Добавить». Радар начнёт снимать с неё цены сам.
- **Добавить страницу конкурента**: открыть конкурента → «Добавить страницу мониторинга» → вставить ссылку.
- **Загрузить Wordstat**: на wordstat.yandex.ru скачать таблицу → «Поисковый спрос» → Импорт → выбрать файл. Нужны колонки: запрос, показы, месяц.
- **Загрузить цены с Ozon/Маркета**: сделать таблицу (продавец; ссылка; название; цена) → «Конкуренты» → Импорт → «Цены конкурентов вручную».
- **Скачать всё**: «Источники» → «Скачать резервную копию базы».

## Если что-то не так
- Страница не открывается — проверьте, что чёрное окно запущено; запустите «Запустить радар» ещё раз.
- В «Источниках» красный статус — этот сайт временно недоступен, остальное работает.
- Первую неделю сигналов «цена изменилась» не будет: нужен второй сбор, чтобы было с чем сравнивать.
