1. Первым действием: `python scripts/bump_version.py` (файл `VERSION`, схема X.Y.Z, Z = номер сообщения). Исключений нет, даже на «тест».
2. Запись в `docs/ЖУРНАЛ_ВЕРСИЙ.md`: `## X.Y.Z — дата` + пункты «- …» языком заказчика.
3. Коммит: `git -c user.name="M22 Radar" -c user.email="radar@m22.ru" commit -m "vX.Y.Z: …"`, в конце сообщения строка `Co-Authored-By: Claude Fable 5.1 <noreply@anthropic.com>`.
4. Последняя строка ответа: «Версия сейчас: X.Y.Z».

## 3. Как запускать и проверять

- Тесты: `python -m pytest -q` (25 тестов, все зелёные на 0.1.85).

Перезапуск: остановить процессы python с `radar serve` в командной строке, затем `Start-ScheduledTask -TaskName 'M22 Product Radar'`. Процессы, запущенные из инструментов агента, умирают вместе с сессией — так сервер не запускать.
- Сборы: `python -m radar full-update` (все источники), `python -m radar collect m22 | radiosync | competitors | trends`; расписание в `radar/scheduler.py` (ночной запуск, catch‑up при пропуске >26 ч, т.к. ПК спит).
- База: SQLite WAL `data/radar.sqlite3`, busy_timeout 30 с. Не запускать больше двух параллельных сборов — ловили «database is locked».

## 4. Устройство (кратко)

Стек: FastAPI + Jinja2, requests/BeautifulSoup, APScheduler, openpyxl, pytrends, PIL+numpy.

| Модуль | За что отвечает |
|---|---|
| `radar/collectors/m22.py`, `radiosync.py` | наши сайты, все разделы каталога, robots игнорируются (свои сайты) |
| `radar/collectors/competitor_generic.py` | сайты конкурентов: обход, карточки, JSON‑LD, `specs_extract`, фильтры мусора (новости, портфолио, поставки), автоотключение мёртвых страниц (5 пустых прогонов, robots, 3× 403/404/410) |
| `radar/normalize.py` | категория, тип изделия (kind), код модели (`MODEL_HINTS`: Retekess, Reinvox, Bosch, Synexis…), вместимость, «вне контура» |
| `radar/matching.py` | сопоставление конкурент ↔ M22: exact_model, **identical** (таблица алиасов в настройках, напр. T130/T130S/T131 → SGTR02; одинаковые фото), direct_analog, functional, kit, accessory, substitute, adjacent, new_category |
| `radar/image_match.py` | pHash/dHash фото: одинаковые (≤6) → identical, похожие (≤12) → только подсказка |
| `radar/pricing.py` | «Пересмотр цен»: по каждому товару M22 медиана рынка (≥3 предложения от ≥2 продавцов, порог 10 %), вердикт снизить/поднять/держать; кнопка пересчёта, экспорт xlsx |
| `radar/assortment.py` | «Что ввести»: каждая модель конкурента против матрицы M22 по категории и типу; вердикты gap / consider / covered / no_data |
| `radar/competitor_matrix.py`, `site_categories.py` | матрица конкурентов, сводка, покрытие категорий (считаются модели, не строки), задекларированные категории сайтов, блок «вне контура» с темами и ссылками |
| `radar/signals.py`, `recommendations.py` | сигналы и действия: стабильные ключи, обновление на месте, автозакрытие при исчезновении условия — дублей быть не должно |
| `radar/site_audit.py` | ошибки на m22.ru/radiosync.ru, наличие |
| `radar/web/app.py`, `templates/` | все экраны; главная — дашборд; «Логика радара» = `docs/ЛОГИКА_РАДАРА.md` |

Уровни продавцов: A — ключевые конкуренты, B — вторичные, C — косвенные, **M — маркетплейсы** (Wildberries, Ozon: не конкуренты, цены динамические, везде помечены). Порядок A, B, M, C.

## 5. Решения заказчика, которые нельзя откатывать

- Retekess T130 = SGTR02 — «идентичное оборудование», не аналог.
- Wildberries/Ozon — маркетплейсы, отдельный уровень M, пометка «цена динамическая».
- Интерком у M22 есть; голосовых усилителей у M22 нет — это нормально, не ошибка.
- Комплекты M22 на составляющие пока не делить (отложено заказчиком).
- «Что ввести» не должно опираться на число продавцов (все торгуют своим брендом).
- Экраны без дублей действий; «одна тема — одно место» (см. `docs/ЛОГИКА_РАДАРА.md`).
- Firecrawl подключать только если заказчик положит `FIRECRAWL_API_KEY` в `.env`.

## 6. Технические грабли

- Bash‑heredoc портит `\b` в регулярках (превращает в 0x08). Патчи с regex писать через Write или python‑файл.
- В Jinja ключи словаря `items`/`values` конфликтуют с методами dict → 500. Использовать `offers`, `cats`, `.get('items')`.
- Относительные URL фото/карточек абсолютизировать `urljoin`.
- Google Trends отдаёт 429 → повтор до 4 раз с паузой 120·n с.
